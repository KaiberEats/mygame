# 要求仕様 (Requirements)

`joker in the deck` のゲーム仕様。本書は「何を作るか」を定義する（「どう作るか」は [ARCHITECTURE.md](ARCHITECTURE.md)）。

## 1. コンセプト

人狼ゲームの問題点である

- 死んだあと暇である
- 役職を持たない村人が暇である

を解消するため、**人狼ゲームとババ抜きを混ぜ**、人狼を流動的にし、かつ死なないようにした対戦ゲーム。

## 2. 世界観

超次元の存在によってボードゲームの駒にさせられてしまった人達が、ゲームをさせられている。**神の箱庭**。joker を所持している間、joker に意識を奪われそうになる。

> 演出のトーン指針: 「荘厳な箱庭 / 幾何学」と「joker ＝ 不吉・侵食する黒」の対比。

## 3. コアルール

| 項目 | 内容 |
|---|---|
| 手札 | 開始時に 2 / 4 / 6 / 8 枚を配る |
| デッキ | トランプ（基本 4×13 + joker = 53 枚）。人数に応じて変更可 |
| ペア破棄 | 手札にペアがあるとき対応キーで捨てられる。捨てたペアの**数字に応じて異なる能力が発動**（→ 第5章） |
| クールタイム | カード破棄には一定のクールタイムがある |
| 補充 | 手札が減ると全員共通の山札から自動補充。山札が無ければ補充なし |
| 勝利 | 手札を 0 枚にしたプレイヤーの勝利 |
| 時間切れ | 制限時間に達するとゲーム強制終了。**手札が少ないほど上位**。joker 所持者は最下位 |

## 4. joker / kill / change / stun

- joker は開始時の配布で**必ずいずれかのプレイヤー**に渡る。
- **kill**: joker 所持者は他プレイヤーに近づくと kill できる。
- **stun**: kill されたプレイヤーは **10秒間**スタン（行動不能）。
- **change**: joker 所持者は kill したプレイヤーに対して change でき、**自分の手札の一番右のカード**と対象の**ランダムなカード**を交換する。
- **スタン解除後**: 数秒間、無敵かつ移動速度上昇。

## 5. 能力仕様（ペアの数字ごと）

各能力には通常版と、能力13で付与される**強化版（' / ダッシュ）**がある。

| # | 通常 | 強化（'） |
|---|---|---|
| 1 | 手札を全て山札に戻しランダムに引き直す | 可能な限りペアの状態で引く |
| 2 | アイテム「ミサイル」入手。使用で対象にミサイル→着弾でスタン、壁で消滅 | ミサイル2発 |
| 3 | 5秒間無敵 | 10秒間無敵 |
| 4 | アイテム「鎌」入手。使用で対象を kill（change 不可） | 一定期間、鎌の範囲に入った相手を自動 kill |
| 5 | 最も近いプレイヤーの手札を一定期間見る | 全員の手札を一定期間見る |
| 6 | 状態異常を解除（スタン、能力5、能力11 の効果等） | 一定期間、状態異常を受けると自動解除 |
| 7 | 10秒間透明 | 20秒間透明 |
| 8 | アイテム「コイン」入手。使用で対象に change、かつ一定期間足が速くなる | コイン2個 |
| 9 | アイテム「レイピア」入手。3秒間、kill されるとカウンター（自分はスタンせず相手をスタン） | 継続6秒 |
| 10 | 手札の一番左のカードをコピー | 2枚コピー |
| 11 | 10秒間、マップに全プレイヤーの位置表示 | 20秒間 |
| 12 | アイテム「シールド」入手。所持中、一度だけ攻撃を防ぐ | シールド2個 |
| 13 | 発動後、次に使う能力を強化（'版にする） | アイテム「剣」入手。一度だけ使用、対象を kill。change 可、無敵/レイピア/シールド等を貫通 |

## 8. 非機能要件

- **マルチプレイ**: EOS（ロビー/マッチメイク）＋ ENet（IP直結の LAN）。
- **多言語**: 日本語 / 英語。
- **設定**: 画面、キー割り当て、言語、プレイヤー名・色、UIサイズ。
- **対応OS**: Windows / macOS / Linux。
- **公開前提**: 外部公開を想定。秘密情報の扱いは未決定（[ARCHITECTURE.md#secrets](ARCHITECTURE.md#secrets)）。
